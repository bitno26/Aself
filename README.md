# سجل متابعة الحضور

**Aself** - تطبيق ويب لتتبع الحضور يعمل بدون اتصال بعد التحميل الأول، ويمكن تثبيته على الهاتف والكمبيوتر.

## المميزات

✅ **يعمل دون اتصال** - التطبيق يعمل بالكامل دون اتصال بعد التحميل الأول  
✅ **قابل للتثبيت** - يمكن تثبيته على الهاتف أو الكمبيوتر مثل التطبيق الأصلي  
✅ **بيانات خاصة** - جميع السجلات تُحفظ فقط في متصفحك على جهازك. لا يتم إرسال أي شيء إلى أي خادم.  
✅ **بسيط وسهل** - واجهة نظيفة وبديهية لتتبع الحضور  

## كيف يعمل

1. افتح التطبيق في المتصفح
2. ابدأ بتتبع سجلات الحضور
3. تبقى جميع البيانات على جهازك - خاصة تمامًا
4. قم بتثبيته كـ PWA على الهاتف أو سطح المكتب لتجربة تشبه التطبيق

# Attendance Tracking Log

**Aself** - A web application for attendance tracking that works offline after the first load and can be installed on your phone and computer.

## Features

✅ **Works Offline** - The app functions completely offline after the initial load  
✅ **Installable** - Install on your phone or computer like a native app  
✅ **Private Data** - All records are saved only in your browser on your device. Nothing is sent to any server.  
✅ **Simple & Easy** - Clean, intuitive interface for tracking attendance  

## How It Works

1. Open the app in your browser
2. Start tracking attendance records
3. All data stays on your device - completely private
4. Install as a PWA on mobile or desktop for app-like experience

## Installation

Visit the app at: [https://bitno26.github.io/Aself](https://bitno26.github.io/Aself)

Or clone the repository:
```bash
git clone https://github.com/bitno26/Aself.git
cd Aself
```

## Privacy

Your data is yours alone. Everything is stored locally in your browser with zero server communication.

## Technology

Built with JavaScript - a modern, lightweight web application.
